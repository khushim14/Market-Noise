Architecture

Full-Stack System Overview

Data Pipeline

From raw news → scored narrative

Background Scraping

Celery Beat fires every 30 minutes. One task per active ticker runs in parallel. 4 scrapers per ticker.

FinBERT Inference

Batch size 32. GPU auto-detect (MPS/CUDA → CPU). 440 MB cached model. ~10× faster than one-by-one.

On-Demand Cache

First call ~2–5s. Subsequent calls <100ms from Redis. 8 distinct cache keys, 10–30 min TTLs.

NLP

Why FinBERT — not just VADER

❌ VADER (General NLP)

"Beat estimates but raised guidance cut"

Sentiment: NEGATIVE ✗

Rule-based lexicon — counts positive/negative words. Misses financial domain nuance.

✅ FinBERT (Financial BERT)

"Beat estimates but raised guidance cut"

Sentiment: POSITIVE ✓

Pre-trained on 100k+ Reuters reports, earnings calls, FPhrasebook. Understands context.

Output per article

Positive0.82
Negative0.10
Neutral0.08
Compound score: +0.72  ·  Label: Positive

Exponential decay weighting

Articles decay with half-life of 3 days. Today's coverage counts far more than last week's.

weight = exp(−λ × age_days)
λ = ln(2) / 3   # half-life 3 days
avg = Σ(score × weight) / Σ(weights)

Scoring

3-Factor Hype Score Model

Classification

6 Narrative Archetypes — Explainable AI

Rule-based classifier — no black-box ML. Users can see why a stock is flagged.

🔥 Short Squeeze Dynamics

Extreme Risk

Extreme bullish + accelerating velocity + imbalanced + high hype. GME/AMC pattern — high-vol reversal risk.

😨 Macro Fear Pattern

High Risk

Sustained negative + broad coverage + elevated hype. Market anxiety around Fed decisions, regulation.

🌊 Theme/Sector Wave

High Risk

Positive + accelerating + diverse sources + high hype. Sector rotation — AI boom, clean energy, crypto cycles.

📉 Narrative Cool-off

Moderate

Velocity decelerating + previously high hype + coverage dropped. Story fading, retail attention moving elsewhere.

⏳ Pre-Catalyst Build

Moderate

Accelerating mentions + neutral/reserved tone. Anticipatory build — earnings, FDA decision, product launch.

✅ Balanced Coverage

Low Risk

No unusual signals. Routine, diversified coverage — healthy information flow, no amplification bias.

Features

What users see on the Stock Page

📈 Live Price + Chart

Twelve Data OHLCV. Range selector: 1D / 7D / 1M / 3M. Recharts AreaChart with gradient fill. Price change badge updates dynamically.

🧠 Narrative Summary

Gemini / Groq generates a 3–4 sentence plain-English summary grounded in the current sentiment, velocity, and pattern data. No speculation. Cached 15 min.

📰 News Aggregation

GNews + RSS. Each article shows sentiment label, compound score, source, and time. Sorted by recency. Clicking awards +10 XP.

📊 Analysis Cards

4-card grid: Sentiment (−1 to +1), Narrative Velocity (0–100), Hype Score (0–100), Pattern Archetype. Animated bars, tooltips, color-coded.

⏱ Narrative Timeline

91-day rolling chart (Recharts). Shift detection — annotated when narrative meaningfully changed direction. Window stats: 7d / 30d / 90d.

💬 AI Chat Panel

Sticky sidebar. Users bring own Gemini/Groq key (encrypted at rest with Fernet). Context-aware — chat knows current sentiment, velocity, headlines.

# Fernet symmetric encryption

encrypted = f.encrypt(raw_key)

# Decrypted only at request time

Each user's Gemini/Groq key stored encrypted. Decrypted in memory only when making LLM call. Never surfaced via API.
